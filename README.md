# Aditya Jadhav · Data Analyst Portfolio

Personal portfolio: projects, skills and resume.

**Live:** https://adityajadhav.vercel.app

## Projects featured
- **ProductIQ:** live AI product strategy app (Python, MySQL, Power BI, Gemini API)
- **AstroSage Call Centre:** where to invest ₹1 crore (Excel, Pivot Tables, dashboard)
- **Chinook Music Store:** churn and customer risk analysis (SQL, CTEs, window functions)

## Built with
Next.js (static export), React, Lenis smooth scrolling, Vercel hosting and analytics.
Fonts: Manrope and JetBrains Mono, self-hosted.

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000

## Update content
- Resume: replace `public/Aditya_Jadhav_Data_Analyst_Resume.pdf` (keep the same file name)
- Project screenshots: `public/images/`
- Website address used in link previews: `app/site.js`
